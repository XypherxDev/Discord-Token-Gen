⚡ EV Gen Discord Token Generator

A tool designed to generate Discord tokens unlimted times. This project is intended for developers and researchers who want to understand how token systems and automation workflows function.

🚀 Features
Fast token generation
Lightweight and easy to run
Simple configuration
Designed for testing environments

📦 Installation
git clone https://github.com/your-repo/ev-gen-token-generator.git
cd ev-gen-token-generator
pip install -r requirements.txt

▶️ Usage
python main.py

Follow the on-screen instructions to start generating.
